# Termux Dotfiles

A minimalistic dotfiles setup for terminal emulator on mobile. Sets up ZSH shell with OMZ aliases, as well as some common tools like `git` and `openssh`.

## Usage

From a new [Termux installation](https://termux.dev/en/), execute:

```sh
sh $(curl -fsSL https://raw.githubusercontent.com/DTopping256/termux-dotfiles/refs/heads/main/remote-install.sh)
```
